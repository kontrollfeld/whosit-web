# whosit sound mark

`whosit-klangzeichen.mp3` (with voice: "whosit?", then the Morse answer **ME** − − ·, 4.6 s) and
`whosit-klangzeichen-ohne-stimme.mp3` (the answer only, 2.6 s). Played in `public/app.js`:
the answer when the other side arrives, the full mark once when a call connects — only on
instances without operator branding (`EUDI_BRANDING`); branded instances keep the neutral chime.

Like the logo, these are brand assets: copied unchanged from the media kit
(`media-kit/klang/`, where the source scripts and the WAV originals live). The licence covers the
files; it grants no right to the sound mark as a trademark. A new version comes from the media
kit, not by editing these files.
